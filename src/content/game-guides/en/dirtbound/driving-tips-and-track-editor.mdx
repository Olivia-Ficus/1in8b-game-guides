These are practical route-reading habits, not tested lap-time claims. Use them to keep a run clean before trying to drive faster.

## Three ways to keep a run together

1. **Brake before a bend, then accelerate on exit.** Waiting to brake until the car is already sliding wide makes the correction larger and slower.
2. **Stay on the dirt.** Grass costs speed, and going off-route or getting stuck can result in a five-second reset penalty.
3. **Save a good stage URL.** Each generated stage has an identifier in its URL. Copy it before leaving if you want to replay the exact same road or share it with a friend.

<Callout type="tip" title="A repeatable road is useful practice">
  Reopening a saved stage URL lets you compare a line against your own earlier attempts instead of learning a new route every time.
</Callout>

## Create, test, and publish a circuit

<figure class="not-prose overflow-hidden rounded-xl border bg-card"><img src="/images/games/dirtbound/editor-route.jpg" alt="DirtBound Circuit Editor with a route drawn through editable track points" loading="lazy" /><figcaption class="p-4 text-sm text-muted-foreground">Official DirtBound Circuit Editor: shape a circuit, test it in the game, then publish it for other players.</figcaption></figure>

The Track Editor is for circuits rather than generated stages. Shape a route, test it in the game, then publish it when it is ready for other players. Publishing uses an account. The current review did not verify custom scenery placement, so this guide does not claim that trees or decorations can be added.

## When to use each feature

| Player goal | Best place to start |
| --- | --- |
| Drive a fresh solo road | Stage |
| Improve a repeatable lap | Circuit |
| Compare on one shared road | Daily Challenge |
| Race together | Multiplayer or a shared stage URL |
| Build a route for others | Track Editor |
